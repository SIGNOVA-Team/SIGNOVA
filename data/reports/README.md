# Data Reports & Registers Guide

يحتوي هذا المجلد على التقارير الفنية وسجلات التتبع الرسمية لجودة وحوكمة البيانات في مشروع **SIGNOVA**:

---

## 📄 الملفات

1. **`dataset_sources.csv`**:
   - السجل الرسمي لجميع مصادر البيانات ذات الأولوية (P0 المصرية، P1 WLASL، P2 How2Sign، P2 ArabSign، P2 KArSL).
   - يسجل الروابط الرسمية، الإصدارات، التراخيص، الاستخدام المصرح به، وأسباب الاعتماد أو التقييد.

2. **`download_manifest.csv`**:
   - الفهرس الشامل لجميع روابط الوسائط (فيديوهات أمامية، جانبية، عمق Depth، ونقاط الهيكل العظمي 2D/3D Keypoints).
   - يشمل معرفات Google Drive، الأحجام المتوقعة، وبوابات الحصول على إذن التنزيل.

3. **`qc_flags_p2.csv`**:
   - جدول ملاحظات الجودة المسجلة بصيغة قابلة للقراءة آلياً (`QC-P2-001` إلى `QC-P2-005`) مع تصنيف الأهمية واستراتيجية المعالجة.

4. **`qc_report_p2.md`**:
   - التقرير الفني الشامل لتدقيق جودة البيانات، المقارنة اللغوية بين لغة الإشارة العربية والمصرية، وتقييم متطلبات السعة الحاسوبية والتخزينية.
