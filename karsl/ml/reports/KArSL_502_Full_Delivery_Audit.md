## Decision

The frozen CNN can be loaded and called from the separately held private inference bundle. The numerical research results, code, notebook and proposed Python contract are real. A subsequent branch-candidate package adds a standalone GRU training script and broader smoke tests in `karsl/ml/`. Full GPU training on the controlled frozen train/validation shards has now been replayed for both architectures from a clean extracted code package. The GRU's 23 history rows and all 20 model tensors match; its checkpoint bytes differ because of an added configuration field. The CNN checkpoint is byte-identical to the original, its 18 history rows match, and all 22 tensors match. The original calibration and terminal test protocols have also been replayed from the clean-extracted code package; the calibration config, test protocol, primary per-class CSV, confusion matrix and test metrics match the originals. Neither compact ZIP contains the full training inputs. The model is not suitable as an accepted-sign translator: its frozen acceptance policy returns `uncertain` for every prediction. Public release and approved downstream use remain subject to source rights, provenance and semantic review.
